# Australian Cycling Events Map

A web application that displays local cycling events on an interactive map, with data sourced from AusCycling, West Coast Masters CC, and other Australian cycling organisations.

## Features

- **Interactive map** with clustered markers (Leaflet.js + MarkerCluster)
- **Filter by discipline** - Road, Criterium, Track, MTB, Gravel, BMX, Cyclocross
- **Filter by source** - AusCycling, West Coast Masters CC
- **Filter by state** - WA, VIC, NSW, QLD, SA, TAS
- **Distance filtering** - Use your browser's geolocation to filter events within a radius
- **Date range filtering** - Show only events in a specific date window
- **Sortable event list** - Sort by date, distance from you, or name
- **Dark theme** with discipline-specific colour coding

## Architecture

```
index.html          - Main page (static, no build step)
static/
  app.js            - Frontend application logic
  style.css         - Styles (dark theme)
data/
  events.json       - Event data (generated by scraper)
scraper/
  base.py           - Base scraper class and CyclingEvent dataclass
  auscycling.py     - AusCycling event scraper
  westcoast_masters.py - West Coast Masters CC scraper
  run.py            - Scraper runner (outputs data/events.json)
```

## Usage

### Run locally

Just open `index.html` in a browser, or serve with any static file server:

```bash
python -m http.server 8000
```

### Update event data

```bash
pip install -r scraper/requirements.txt
playwright install chromium --with-deps
python -m scraper.run
```

The scraper uses Playwright (headless Chromium) to bypass Cloudflare bot protection and render JS-driven content from AusCycling, EntryBoss, WCMCC, and WestCycle.

## Data Sources

| Source | URL | Method |
|--------|-----|--------|
| AusCycling | auscycling.org.au/events | Playwright headless browser |
| West Coast Masters CC | wcmasterscycling.asn.au | Playwright + WordPress REST API |
| EntryBoss | entryboss.cc/calendar/westcoastmasterscc | Playwright headless browser |
| WestCycle | westcycle.org.au | Playwright headless browser |
